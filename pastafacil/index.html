Privacidade

  • Nada sai do seu computador. A lista de nomes, os arquivos que você envia e as pastas geradas são processados 100% dentro do seu navegador.
  • Sem servidor. O PastaFácil não tem backend nem banco de dados - não existe um lugar remoto onde seus dados fiquem guardados.
  • Sem conta, sem login. Não é preciso se cadastrar nem informar e-mail pra usar a ferramenta.
  • O que fica salvo, fica só no seu navegador. "Minhas listas salvas" e as preferências de tema/idioma usam o armazenamento local do navegador (localStorage/IndexedDB) - some se você limpar os dados do site, e nunca é enviado a lugar nenhum.
  • Reconhecimento de texto em imagem (OCR) também roda localmente, via WebAssembly - a foto nunca é enviada para nenhum serviço externo.
